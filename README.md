# Editable PPTX Export

Плагин экспортирует выбранные фреймы Figma в `.pptx`. Текст, прямоугольники,
эллипсы и линии создаются нативными объектами PowerPoint. Векторы, сложные
заливки, маски и эффекты сохраняются отдельными SVG/PNG-объектами, чтобы не
терять внешний вид.

Интерфейс доступен на русском и английском языках. Переключатель `RU / EN`
находится в шапке, выбранный язык сохраняется между запусками плагина.

## Локальный запуск

1. Установите зависимости: `npm install`.
2. Соберите проект: `npm run build`.
3. В Figma Desktop откройте **Plugins → Development → Import plugin from manifest…**.
4. Выберите `manifest.json` из корня проекта.
5. Выделите один или несколько фреймов и запустите плагин.

Для разработки используйте `npm run dev`. После изменений интерфейса перезапустите
эту команду, затем перезапустите плагин в Figma.

## Что редактируется

- Текстовые слои, включая смешанные начертания и размеры.
- Прямоугольники, скруглённые прямоугольники, эллипсы и линии.
- Сплошные заливки, обводки, прозрачность и базовое выравнивание текста.
- SVG и PNG остаются отдельными перемещаемыми и масштабируемыми объектами.

## Текущие ограничения

- PowerPoint должен иметь установленные шрифты, использованные в Figma.
- Маски, blur, тени, градиенты и сложные векторы не раскладываются на внутренние
  редактируемые контуры.
- Формат всех слайдов определяется первым выбранным фреймом; фреймы другого
  соотношения сторон вписываются по центру.
- Сложные повороты вложенных слоёв могут немного отличаться от Figma.
